🔹 Combinational Circuits – SSI

Small Scale Integration (SSI) circuits contain a small number of logic gates. These are the building blocks of digital systems.

AND Gate

IC 7408
Output HIGH only when both inputs are HIGH

OR Gate

IC 7432
Output HIGH when any input is HIGH

NAND Gate

IC 7400
Inverse of AND gate

XOR Gate

IC 7486
Output HIGH when inputs differ

🔁 Sequential Circuits

Unlike combinational circuits, sequential circuits depend on present inputs and past outputs. They store data using memory elements called flip-flops.

SR Flip-Flop

SR Flip-Flop has two inputs: Set (S) and Reset (R). It is the basic memory element.

SRQ
00No Change
010
101
11Invalid

D Flip-Flop

D Flip-Flop eliminates the invalid state of SR flip-flop. The output follows the input on clock edge.

DQ(next)
00
11

JK Flip-Flop

JK Flip-Flop removes the invalid condition of SR flip-flop and introduces toggling behavior.

JKQ(next)
00No Change
010
101
11Toggle
🧠 Flip-flops are the foundation of counters, registers, and memory.
